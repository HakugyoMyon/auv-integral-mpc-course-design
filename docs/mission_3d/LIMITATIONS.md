# 适用范围与尚未验证的边界

本工程是离线 MATLAB 模型在环（MIL）课程仿真。只对验收表中归档的工况、配置和源代码版本作通过声明，不把组件测试当整机验证，不保证任意任务、任意随机障碍场均可完成。

- 控制量为推进器推力与四个舵面的指令，经过执行器动态和六自由度物理对象；不使用PID，不直接改位姿。
- 目前使用0.8m/s、最小转弯半径25m、参考变深率上限0.06m/s及声明的舵角/舵速/攻角条件。模型参数含待实艇辨识的假设。
- 静态避障使用新增的多俯仰角三维几何扫描假设（60m，水平±65°、俯仰±35°），并非现有单前视声呐或机械模型已具备的三维成像能力。没有仿真真实声学混响、散斑、漏检或扫描运动畸变。
- 人工确认的启动自由空间仅为NED[2,0,14]m、半径8m球体。其余未观测空间不会作为已验证自由空间提交。
- `whole_ball_free_fusion`仅适用于静态世界：完整体积自由证书可排除旧测量的可能占据外包；普通射线、概率性未检出和启动先验不能替代此条件。它不是OctoMap的逐射线清除实现，更不适用于移动障碍物。
- 导航95%/3σ包络与0.5m跟踪管是声明的模型假设。每条归档轨迹另作经验检查；经验未超界不等于统计校准、全时间联合概率或实海确定性保证。
- 碰撞与物理审计使用0.01s样本，预测管审计使用0.1s样本；不声称连续时间形式化证明。物理碰撞观察器仅用于把失败航次判失败，不给规划器提供障碍真值。
- 无局部可行候选时停止的是仿真，不代表欠驱动AUV已获得实际安全停车、盘旋或上浮退出保证。有限动作库不具有全局完备性和递归可行性证明。
- 已通过航次可能包含较长的绕行和转弯连接，未证明路线最短、时间最优或能耗最优；固定种子通过不是任意随机场成功率估计。
- 本轮按静水条件验证。未把静态避障与强斜流、DVL长时失锁、实际声学底锁、实海传感器误检联合资格化。
- GNSS用于任务前初始对准；水下航次不伪造GNSS。DVL仍是配置性可用窗口与速度测量抽象，不是完整的海底多波束回波模型。
- 区域覆盖和沿线巡检确认的是几何观测证据，不等于真实声学图像、缺陷识别或采样器实物作业。到点任务是有容差的通过式确认，未提供悬停能力。
- 地图和规划按仿真时间同步运行，计算耗时未转化为真实艇体持续航行的异步延迟。模拟航次时长不是实时处理器性能指标；没有SIL/HIL或实艇试验。

随机任务生成器、BAT/EXE一键封装、机械模型动画优化保留为后续任务，本轮不把它们标为完成。
