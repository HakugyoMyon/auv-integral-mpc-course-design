# 复现与验证边界

## 依赖和运行

从仓库根目录执行 README 中的 MATLAB 命令。`project_environment` 仅在调用期间配置 MSS 路径并核对 `remus100` 的解析位置；请避免同时运行另一个版本的同名函数。快速测试需要 Optimization Toolbox；`includeSimulink=true` 另外需要 Simulink。

`python scripts/check_repository.py` 只做静态文件、SHA-256 和可移植性检查，不等价于 MATLAB 数值验证。`test_public_reproduction` 使用数值参考逐样本比较状态和指令，容差为 1e-8。工具箱版本、求解器与浮点计算变化可能造成差异，差异应调查，不能直接删除断言并宣称复现成功。

## 数据和缓存

`reference_data/v3` 是从原冻结结果导出的数值数组；不依赖原开发目录、旧版本 MPC 或旧调参缓存。`scripts/export_reference_data.m` 仅为维护者导出工具，普通使用者不需要执行。

`docs/results` 是原实验记录的静态快照。新实验写入 `results`，不覆盖静态记录。正式比较具备配置签名检查，传感器脚本缓存核对传感器配置；参数探索应使用独立输出目录或清理对应旧缓存，避免混用。

发布适配仅调整参考数据加载、首次运行目录创建和完整性检查等入口逻辑。冻结数值核心保持原始 SHA-256；Simulink 文件仅将作者元数据替换为公开账户名。未修改模型连接、求解器或控制参数。

## 公平对照与统计解释

同一工况使用同一物理对象、初始条件、LOS、速度/深度控制与执行器约束。传感器配对试验使用相同噪声序列，误差指标由真实状态计算。延迟为 1 个控制采样周期（0.1 s），作用于 12 个刚体状态；执行器状态反馈仍假定即时准确。固定随机种子为 104729、130363、155921；每种有噪声条件 3 次，纯延迟条件 1 次，不能视为充分统计显著性检验。

RMSE 采用 t>=30 s；稳态指标采用最后 50 s；TV 采用完整运行时段实际舵角。长短运行之间不能不加说明直接比较 TV。求解时间依赖计算机和运行环境，现有时序记录不构成嵌入式实时性保证。

## 模型与结论边界

MSS 为物理模型来源，包装器增加外力矩及横流阻尼敏感性参数。动力学近似和数值方法是本研究条件，不能由 MATLAB/Simulink 一致性推出实艇正确性。控制结果仅覆盖给定速度、深度和直线/圆形工况。积分 MPC 改善已测工况误差，但理想反馈下舵动作增加；未给出全局稳定性、一般鲁棒性或节能证明。
