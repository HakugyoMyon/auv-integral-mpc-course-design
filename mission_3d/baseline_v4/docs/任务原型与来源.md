# 任务原型及真实作业参照

|界面任务|人工输入|本工程执行与确认|边界|
|---|---|---|---|
|区域巡测|矩形区域、方位、航线间距、作业高度、覆盖阈值|往复式路线，按有效观测确认原始网格，返回家点|几何覆盖验证，不生成实测水深成果|
|设施沿线巡检|已知设施折线、点位间距、有效观测次数、作业高度|沿线观测，原始点位账本与缺测恢复，返回家点|不检测真实管线或识别缺陷|
|三维测站通过式访问|NED位置、优先级、到达及深度容差|满足导航误差约束的向前通过，原始点ID持久，返回家点|不承诺悬停或操作采样泵|
|航渡/返航|终点、深度与家点|独立任务配置、置信到达及经MPC准入的运行中返航请求|初始本地原点对准，不做实物停靠|

巡检作业参照KONGSBERG公开的HUGIN管线检查流程（真实产品采用声呐、相机等多载荷，不能将其成像性能归给本工程）：[厂商原始案例](https://www.kongsbergmaritime.com/news-and-events/news-archive/2011/kongsberg-hugin-completes-worlds-longest-multi-sensor-auv-pipeline-inspection/)

有效观测而非仅走过航线的任务判据，参考Zacchini等的感知驱动水下检查研究：[Zacchini等，2022](https://doi.org/10.1002/rob.22061) 。本工程未复现其FLS三维占据重建、NBV或RRT*算法，只借鉴按传感反馈评价作业进度的任务组织原则。

本版使用明确无障碍场景，0.8m/s，R>=25m；定深与离底高度区分，任务结束不等于机器人停在水中。真实工作流在这里缩放为有限水域MIL任务，不代表产品能力或海试。

上述任务组织参照的两项公开原始来源已在最终交付时重新打开核对。工程采用缩放的几何任务和传感器模型，不把真实产品的多载荷性能或论文方法成果当作本工程实验结果。
