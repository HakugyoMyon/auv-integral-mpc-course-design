# 静态感知与地图接口、依据和限制

本目录为新静态阶段的独立组件，不修改已验收v4。主agent统一运行MATLAB检查，本子任务未启动MATLAB。

## 接口

```matlab
c = sta_sensor_config();
packet = sta_sensor(world, xTruth18, captureTime, c, RandStream(...));
map = sta_map_init(prior, c);
[map,event] = sta_map_update(map, packet, captureNav);
q = sta_map_query(map, pointsNx3, queryRadius);
result = sta_perception_contract(outputFolder);
```

- `world`仅传给传感器，含`obstacles`及`terrainFcn`或平底`bottomDepth_m`；可选`surfaceDepth_m`。障碍暂支持sphere的`centerNED/radius_m`和有限cylinder的`centerNE/radius_m/depthLimits_m`。不支持的形状明确报错。
- `packet`仅含时间、有限扫描角格、测距、无效/guard-return/no-return分类和测量误差界，没有世界模型、障碍中心、半径或ID。
- `captureNav`需要`positionNED`、标量在前`quaternion`、`positionErrorBound_m`、`attitudeErrorBound_rad`、`valid`和与packet相同的`time`。延迟包必须用采样时姿态，不能误用收到时刻姿态。
- `prior`只能是明确声明的操作员已确认起始自由球：`operatorVerified=true,centerNED,radius_m,positionErrorBound_m`。不根据障碍真值初始化整条航线。
- 查询的`queryRadius`包含当前艇体截面与当前导航/姿态预算；结果`state=-1/0/1`分别是未知/可证自由/guard排除，`clearance`是已减查询半径的自由球余量。未知不当自由。

## 为什么需要垂向观测

旧d13/d15仍以单水平射线为基础，旧d18主要是XY动态目标可达域，不能直接证明三维上下通行。EROAS通过旋转二维声呐获得垂向信息，明确区分二维FLS与有仰角信息的扫描；其平台是可悬停REXROV2，不能把其执行层直接照搬给本欠驱动艇。[EROAS v3原文](https://arxiv.org/html/2411.05516v3)

有限波束的实际AUV研究也将探测误报/漏检与避障决策联系起来，不能把真实声呐无回波无条件解释为空闲。本目录采用的是明确的几何MIL简化，不宣称复现其声学或损失决策模型。[Morency等原文](https://arxiv.org/abs/2309.05785)

## 当前模型假设

1. 声呐模型可在一次有限周期内取得多仰角信息；默认方位±65°、仰角±35°、1°角格、60m量程、1Hz、0.1s延迟。这是课程MIL能力假设，不表示现有CAD声呐已具有该机械扫描能力，也没有模拟真实扫描转台动态。
2. 完整有效几何扫描内的静态形状能被有限角格检测，测距误差为显式有界均匀误差；可发生整帧丢失，丢失帧不生成自由证书。没有声学阴影以外的材料弱回波或未标记漏检模型，不可据此声称实艇确定安全。
3. 为避免零宽射线间漏障，传感器先按最大量程下角格角点与中心射线的最大空间偏差扩张几何，再求保守首交前缀。因此返回点是有限角格的保守guard边界，不是精确物理表面点；它可能保守拒绝真实空闲区域。
4. 水面和海底先遮挡后方信息；海底数值步长加Lipschitz梯度上界保护，当前基线合成海底声明梯度范数小于0.07。
5. 地图保存guard排除点及整帧射线前缀，不读取真值、不按时间扩张运动可达域。保存最多160个自由扫描证书以控制查询成本，较早自由空间可退为未知；静态guard点不因失观运动扩张。
6. 整个查询球必须落在一个有效扫描扇区/前缀中，球覆盖的所有方位和仰角格取最小前缀，而非仅判断球心或单波束。每帧7层movmin缓存避免逐点遍历全部射线。

## 误差计入位置（各来源一次）

- 有限角格空隙：传感器几何guard内。
- 测距误差：自由前缀减一次；guard点定位误差加一次。
- 采样帧位置：地图自由球收缩和guard点定位预算。
- 采样帧姿态：声呐挂载杠杆臂造成的原点位移`2*|mount|*sin(theta/2)`，加射线方向角误差；不能只算测距端点而漏挂载位移。
- 体素量化：guard点定位增加半体素对角线一次，自由前缀不栅格化。
- 当前艇体/当前导航：查询半径，由主流程构造；长艇建议用覆盖真实包络的多球capsule，样点间距误差与当前姿态杠杆臂也必须覆盖。

若传入的是95%/3σ导航包络，上述证书只能解释为条件于这些包络的保守几何检查，不能把统计协方差包装成无条件确定保证。最终必须由主流程做实际6DOF轨迹、全艇连续碰撞、执行器、任务确认与返航审计。

## 当前检查

`sta_perception_contract`包含空闲/未知/球体与有限柱体遮挡、有限角格漏隙保护、水面/海底、整个球而非球心、延迟姿态拒绝、无效导航、静态记忆和挂载杠杆臂的合成断言。它不是完整任务验收。

## 起始先验与首帧自由证书交接（集成约定）

本次MIL使用操作员预先确认的局部自由球`centerNED=[2;0;14] m,radius_m=8 m`；它只是起始部署水域先验，不是传感器发现的空闲区，也不初始化整条任务路线。场景生成和离线审计必须验证该球处于水体内且不与障碍物相交。基线海底在(2,0)约23.05m深，中心深14m；结合声明的海底梯度界0.07，水体余量约9.05m，大于`8+0.07*8=8.56m`。这一计算只支持该指定基线场景，不能推广成未知实际海域保证。

有限仰角扫描有近场证书空隙：若当前查询球半径与采样帧位置界之和为rho，半仰角为alpha，则即使中心射线无遮挡，整个球进入扫描锥也至少需要距离`d>rho/sin(alpha)`（还须满足其他边界）。例如rho约2.93m、alpha=35deg时需约5.1m。起始自由球必须与首个有效扫描所能证明的整个艇体/导航包络空间重叠，不能仅保证两者中心射线相连；第一有效导航帧立即采样有助于减少交接等待。扩大先验不改变声呐FOV或误差界，且必须显式由操作员确认和场景离线核验。

## 查询性能与容量更新

guard容量上限提高为750000体素；超限仍明确退为全未知，不删除障碍制造自由空间。查询先统一检查所有guard，再按最新扫描优先，仅处理尚未取得完整球自由证书的点；guard始终覆盖自由证书。`clearance`现在是首个成功扫描证书或起始先验提供的保守余量下界，不再是所有历史证书余量的最大值。状态分类不因这项提前终止优化改变。优化前文件保存于archive/*.m.bak，不作为MATLAB函数加入路径。

## 下视传感器遮挡包装器

`sta_altimeter`和`sta_payload_sensor`与原函数参数一致，末尾新增`world`，只在传感器模拟侧使用障碍真值。先调用原函数保留随机序列和时间，再单向使遮挡报文失效，不把障碍顶面伪装成海底。高度计使用有限线段对球和有限柱体求交；载荷使用原点及四角/中心海底交点的凸包，按允许局部平面偏差保守外扩，对整个成像体做支持平面排除。无法证明障碍与成像体分离时拒绝该帧，因此可能保守失效，但不会仅凭五条射线无遮挡就确认整个图像空闲。

高度计包装器已经移除原函数的采样真姿态/真深度字段；调用方不应再次无条件rmfield。附加报文仅有occlusionChecked、occluded、occlusionScope，不含障碍位置/形状。当前DVL仍是可用窗口与噪声抽象，没有加入障碍物导致的底锁丢失模型；这些包装器也不是实际声学传播或图像形成模型。`sta_downlooking_contract`是独立合成检查，需主MATLAB会话执行后才能声称通过。
